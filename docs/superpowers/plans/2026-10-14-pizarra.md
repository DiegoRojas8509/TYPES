# Pizarra creativa + audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reemplazar las páginas de texto por pizarras `.canvas` con bloques gráficos que Diego y Claude editan, y agregar dictado por micrófono local al chat.

**Architecture:** Un `.canvas` es JSON Canvas con tipos extra, texto plano que Claude lee y escribe. `BoardView` (React Flow controlado) usa el `DocumentController` existente para cargar/guardar y un merge por id cuando el disco cambia bajo cambios locales. El audio se graba en el webview, Rust lo transcribe con ffmpeg + whisper-cli y el texto entra en la caja del chat.

**Tech Stack:** Tauri 2, Rust, React 19, TypeScript, Vite, Zustand, Tiptap, `@xyflow/react`, `recharts`, Vitest, `cargo test`, whisper.cpp.

**Spec:** `docs/superpowers/specs/2026-10-14-pizarra-design.md`

## Review Focus

- `.canvas` vacío (0 bytes) o con JSON inválido: se abre en solo lectura con aviso, no rompe ni se sobrescribe.
- Nodo con `type` desconocido o campos extra: se conserva intacto al guardar.
- Dos nodos con el mismo `id` (lo puede escribir Claude): se renombra el duplicado, no se pierde ninguno.
- Imagen cuyo archivo no existe: card con aviso "No encuentro la imagen", no pantalla blanca.
- Gráfica con `values` de distinto largo que `labels`, o con valores no numéricos: se dibuja con lo válido.
- Claude y Diego editan el mismo bloque a la vez: aviso de conflicto, nunca pérdida silenciosa.
- Micrófono denegado, sin `whisper-cli`/modelo, o audio vacío: mensaje en español que dice qué hacer; el chat sigue usable.

## Formato `.canvas`

```json
{ "nodes": [ ... ], "edges": [ {"id","fromNode","toNode","label?"} ] }
```
Todo nodo: `id: string, type, x, y, width, height: number, color?: string`.

| type | campos | se ve como |
|------|--------|-----------|
| `text` | `text`: Markdown | Nota (el primer `#` es el título) |
| `file` | `file`: ruta relativa a la carpeta del .canvas | Imagen |
| `group` | `label` | Zona para agrupar |
| `table` | `title?`, `columns: string[]`, `rows: string[][]` | Tabla editable |
| `chart` | `title`, `kind: "bar"\|"line"\|"pie"`, `labels: string[]`, `series: {name, values: number[]}[]` | Gráfica |
| `timeline` | `title`, `items: {date, title, detail?, status: "hecho"\|"en curso"\|"pendiente"}[]` | Línea de tiempo |
| `decision` | `question`, `options: {name, pros: string[], cons: string[]}[]`, `chosen?: string`, `rationale?` | Decisión |
