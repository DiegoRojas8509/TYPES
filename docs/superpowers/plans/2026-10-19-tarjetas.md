# Navegación con tarjetas — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Reemplazar el árbol de archivos por navegación con tarjetas (Inicio → espacio → carpeta → pizarra), con miniaturas, «cuándo cambió y quién» y resaltado de lo que Claude cambió.

**Architecture:** El backend agrega `modified` al árbol, un comando `board_preview` (miniaturas) y un registro de actividad (`actividad.json` en la carpeta de datos de la app, fuera de `espacios/`). El frontend agrega `currentDir` al store y vistas de tarjetas que reemplazan el estado vacío de `DocumentPane`; la ruta (breadcrumb) vive en una cabecera compartida.

**Tech Stack:** Tauri 2, Rust (serde), React 19, TypeScript, Zustand, Vitest, `cargo test`.

**Spec:** `/Users/basti/.claude/plans/es-que-ya-se-functional-peach.md` (sección Diseño) y la decisión de Diego del 2026-10-19: tarjetas con miniatura, cuándo cambió y quién, nombre protagonista; barra lateral plegada por defecto.

## Global Constraints
- Leer `CLAUDE.md` completo antes de tocar código. Interfaz en español; código, identificadores y commits en inglés.
- `lib/api.ts` es la única puerta a Tauri; las features se comunican por stores (importar el store de otra feature está permitido, sus componentes no); `features/shell` es el router.
- Nunca perder datos de Diego; abrir una pizarra no la escribe; borrar manda a la papelera con `{original, trashed}` y se deshace con Cmd+Z (ya existe, reutilizarlo).
- Rutas validadas contra la raíz (`resolve`, `validate_name`); nada nuevo escribe dentro de `espacios/` (la actividad se guarda fuera).
- En disco no cambia nada: carpetas y archivos normales que Claude lee.
- TDD; sin ruido en consola; `pnpm test`, `cargo test --manifest-path src-tauri/Cargo.toml` y `npx tsc --noEmit` verdes antes de cada commit; archivos > ~300 líneas se parten.
- Diseño sobrio y denso, tema claro y oscuro con las variables CSS existentes; usar los tokens de tipografía (`--text-*`); skills de diseño: impeccable y refactoring-ui (sin ejecutar sus scripts).
- Commits en `feat/pizarra`, sin push; cada mensaje termina con `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus
- Una carpeta con 500 archivos o una pizarra de 10 MB no congela la lista (previews perezosos, límite de nodos, caché por mtime).
- `.canvas` vacío o con JSON inválido: la tarjeta muestra una miniatura vacía, no rompe la vista.
- Nombres con acentos, espacios y emoji (NFC/NFD) en rutas, ruta de navegación y renombrado.
- Renombrar o borrar la carpeta que se está viendo: `currentDir` no queda apuntando a algo que no existe.
- La actividad no se inventa: una escritura propia de la app no queda como «Claude»; el punto de «no visto» desaparece al abrir la pizarra y no reaparece solo.
- Teclado: flechas, Enter, Supr y F2 no actúan mientras se escribe en un campo.

### Task 1: Backend — `modified`, `board_preview` y actividad

**Files:** modify `src-tauri/src/workspace.rs` (`TreeNode`, `build_children`), `src-tauri/src/watcher.rs`, `src-tauri/src/claude.rs`, `src-tauri/src/remote.rs`, `src-tauri/src/lib.rs`; create `src-tauri/src/activity.rs`; frontend types only in `src/lib/api.ts` (wrappers).

**Interfaces (produce):**
- `TreeNode` gana `modified: Option<u64>` (ms desde epoch, de `entry.metadata()?.modified()`; `None` si falla). TS: `modified?: number`.
- `board_preview(path: String) -> BoardPreview { nodes: Vec<PreviewNode { x: f32, y: f32, w: f32, h: f32, kind: String }> }`: lee con `read_text_in` (ruta validada), parsea `nodes` con serde tolerante (nodo sin números válidos se omite; JSON inválido o archivo no `.canvas` → lista vacía; no falla), toma como máximo 200 nodos (los primeros), y normaliza a 0..1 por la caja envolvente de todos los nodos. `kind` = el `type` del nodo. Caché en memoria por (ruta, mtime, tamaño).
- Actividad: `activity.rs` con `enum Actor { Tu, Claude, ClaudeCel, Fuera }` (serializa `"tu"|"claude"|"claude-cel"|"fuera"`), `Activity { at: u64, by: Actor }`, `ActivityLog` (Mutex de mapa ruta→Activity, persistido en `<app config dir>/actividad.json` con escritura atómica y debounce ~500 ms; carga al arrancar; descarta rutas que ya no existen al cargar). `record(path, by)`. Comando `activity() -> HashMap<String, Activity>`.
- Clasificación (función pura `classify(claude_running_in_space: bool, remote_on: bool) -> Actor`): cambio detectado por el watcher que NO fue una escritura propia reciente de la app → `Claude` si hay un mensaje de Claude corriendo en ese espacio, si no `ClaudeCel` si el control remoto está activo (`RemoteStatus::On`), si no `Fuera`. Las escrituras de la app (`write_text`, `create_*`, `rename_entry`, `delete_entry`, `save_image`, `import_files`, restore) llaman `record(path, Tu)` y marcan la ruta como «propia» ~2 s para que el eco del watcher no la reclasifique. El estado «Claude corriendo en el espacio X» sale de `ClaudeState` (marca al lanzar `claude_send` y limpia al terminar; guarda la carpeta del espacio).
- El watcher emite además `activity-changed` (sin payload) cuando el registro cambia, para que el frontend recargue.
- TS: `api.activity(): Promise<Record<string, {at: number; by: "tu"|"claude"|"claude-cel"|"fuera"}>>`, `api.boardPreview(path)`, `onActivityChanged(cb)`.

### Task 2: Frontend — navegación con tarjetas

**Files:** create `src/features/home/` (`HomeView.tsx`, `FolderView.tsx`, `BoardCard.tsx`, `FolderCard.tsx`, `FileCard.tsx`, `CardMenu.tsx`, `Breadcrumb.tsx`, `BoardThumb.tsx`, `home.css`, tests); modify `src/store/app.ts`, `src/features/shell/DocumentPane.tsx` (+ test), `src/features/board/BoardView.tsx`, `src/features/editor/Editor.tsx`, `src/features/viewer/*` (solo para usar la cabecera compartida), `src/lib/api.ts`.

**Interfaces (consume Task 1):** `TreeNode.modified`, `api.activity()`, `api.boardPreview(path)`, `onActivityChanged`.

- Store: `currentDir: string | null` (carpeta que se ve cuando no hay nada abierto; `null` = Inicio), `activity: Record<string, Activity>`, `seen: Record<string, number>` (última apertura de cada pizarra, persistido en localStorage con try/catch). Acciones: `browse(dir | null)`, `back()` (sube un nivel; desde un archivo abierto cierra el archivo y deja `currentDir = parentOf(openPath)`), `open(path)` ya existente fija también `currentDir = parentOf(path)` y marca `seen[path] = Date.now()`. `refreshActivity()` se llama al iniciar, en cada `fsChange` (debounced ~150 ms) y en `activity-changed`. Si `currentDir` deja de existir en el árbol (borrada o renombrada), sube al ancestro existente más cercano.
- `DocumentPane`: sin `openPath` → `FolderView(currentDir)` o `HomeView` si es `null`; con `openPath` renderiza una cabecera compartida `Breadcrumb` encima del renderizador del archivo (las cabeceras `.pane-header` propias de BoardView/Editor/visores se adaptan para no duplicar el título: dejan sus controles y quitan el título; ajustar sus tests mínimamente sin debilitarlos). El texto vacío «Abre una pizarra…» desaparece.
- `Breadcrumb`: «Types › Ropa › Clientes › Daring Martin»; cada segmento es botón (`browse`); botón ← y Cmd+[ llaman `back()`.
- `HomeView`: tarjetas de espacios (carpetas de primer nivel, con conteo de pizarras y última actividad) + «+ Espacio» (nombre inline con `NameInput`). Estado vacío «Crea tu primer espacio».
- `FolderView(dir)`: secciones «Carpetas» y «Pizarras» (y «Otros archivos» para .md/.html/imágenes si hay), cuadrícula adaptable 3–4 columnas, tarjetas «+ Pizarra» y «+ Carpeta» (creación con `NameInput` inline; mismas acciones del store que usa el sidebar hoy). Las carpetas `Imágenes` y los `CLAUDE.md` se ocultan salvo con el interruptor actual (`withoutClaudeFiles`, `get/setShowClaudeFiles`); el interruptor vive en un menú «⋯» de la carpeta.
- `BoardCard`: `BoardThumb` (SVG con los rectángulos de `boardPreview`, cargado perezoso al entrar en pantalla con IntersectionObserver y solo recargado si cambia `modified`), nombre (`titleOf`) como protagonista, línea «hace 2 h · tú | Claude | Claude desde el cel | fuera de la app» (usa `activity[path]` y, si no existe, `modified`; formateo relativo en español con función pura `timeAgo(ms, now)` testeada), y punto + barra naranja cuando `activity.by` empieza con «claude» y `activity.at > seen[path] ?? 0`. `FolderCard`: nombre, «N pizarras», y el mismo resaltado si algo dentro cambió por Claude sin ver.
- `CardMenu` («⋯» en cada tarjeta): Renombrar (también F2) con `NameInput`, Eliminar (también Supr) con `ConfirmDelete` y `deleteEntry` (el Cmd+Z existente la restaura). Click abre; Enter abre; flechas mueven el foco entre tarjetas; Esc o Cmd+[ regresan; ninguno actúa si el foco está en input/textarea/contenteditable.
- Las imágenes de `Otros archivos` conservan el arrastre (`TREE_PATH_MIME`) igual que en el árbol.
- Diseño: ver Global Constraints; tarjetas calmadas, nombre protagonista, miniatura en gris, punto naranja = variable de acento existente.
